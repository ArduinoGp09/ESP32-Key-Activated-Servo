PROBLEMS → DESIGN RULES

Each issue created a rule for the final build.

Invisible keypad wiresUse reference-compatible numeric GPIO endpoints.
Serial Monitor absentUse TX/RX monitor links and open the panel after simulation starts.
Held key repeatsWait for release and apply a short debounce delay.
Board/API mismatchUse ESP32 DevKit C V4 and ESP32Servo.

USER-VISIBLE RESULT

Every key has a predictable destination.

Numeric keys select a 20°–180° range. Extra keys provide fixed endpoints, while Serial Monitor reports the accepted command.
